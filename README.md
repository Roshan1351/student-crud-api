# Student CRUD REST API - Spring Boot Project

This is a basic **Student Management CRUD REST API** project built using **Java Spring Boot**.  
It performs CRUD operations using **Spring Data JPA (Hibernate)** and stores data in **MySQL Database**.

---

## 🚀 Features

- Create a new Student
- Get all Students
- Get Student by ID
- Delete Student by ID
- Tested APIs using Postman

---

## 🛠 Tech Stack

- Java
- Spring Boot
- Spring Data JPA (Hibernate)
- MySQL (Workbench)
- Postman

---

## 📌 API Endpoints

### ✅ Get All Students
**GET**
http://localhost:8080/student

### ✅ Get Student by ID
**GET**
http://localhost:8080/student/{id}

### ✅ Create Student
**POST**
http://localhost:8080/create

### ✅ Delete Student By ID
**DELETE**
http://localhost:8080/delete/{id}
